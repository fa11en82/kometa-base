# kometa-base

Welcome to my shared Kometa script.

This is a basic (somewhat redacted) copy of my config for kometa daily runs.
If you would like to implement this as your own config just remove .template from the config.yaml.template and fill in the information required at the bottom, this config uses information from Trakt, MDBList, TMDB, and adds Charts for TMDB, Trakt, AniList, and MyAnimeList (so logins/API connections will be needed where appropriate)

In addition to this script I also keep an asset folder that has 4 sub-directories:
- Anime
- Collections
- Movies
- TV Shows

By keeping them organized this way I can add or replace posters, backgrounds, and title cards as necessary without having to dig too deeply, this is my own personal preference for organization so it is reflected that way in the asset_directory portion of the yaml.
